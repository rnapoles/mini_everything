# Everything-clone

Filename-only fast search tool inspired by **Everything (Voidtools)**.

## Requirements
- Windows 10/11 development machine
- Visual Studio 2019+ (MSVC) or MinGW (for hobby builds)
- C++17 compiler
- (Optional) PCRE2 if enabling advanced regex

## Running
- Many operations require Administrator privileges to open raw volumes: Run CLI as Administrator.
- For development, test against a small VM/volume to avoid accidental damage.
